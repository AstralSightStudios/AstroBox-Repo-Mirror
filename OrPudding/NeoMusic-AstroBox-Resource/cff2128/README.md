# NeoMusic

NeoMusic 是一款专为小米 VelaOS 手表打造的第三方音乐客户端，底层重构，功能焕新，新增本地导入支持
支持在线流媒体、批量下载、离线缓存、存储管理、每日推荐、私人 FM、快捷手势、多语种歌词和云控更新等功能
Lite 档 2.99 元可离线缓存 50 首，Plus 档 4.99 元可缓存 100 首，Pro 档 6.99 元可无限缓存
