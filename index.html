快速开始

将 remote 指向镜像地址，即可享受加速体验。

# 从镜像站克隆
$ git clone https://mirror.astrobox.dev/astrobox-core.git

# 或为已有仓库添加镜像源
$ git remote add mirror https://mirror.astrobox.dev/astrobox-core.git
$ git fetch mirror
